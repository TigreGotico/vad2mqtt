# Agent Onboarding — vad2mqtt

## Project purpose

Real-time Voice Activity Detection to MQTT bridge built on
ovos-plugin-manager. Turns any OVOS VAD plugin into a Home Assistant
sensor.

## Build / test

```bash
pip install -e .
python -m vad2mqtt          # CLI entry point
```

## Test locally

```bash
# Docker (PipeWire host — mounts socket)
docker compose up -d

# Native (needs mic access)
env MQTT_HOST=192.168.1.116 MQTT_USER=miro MQTT_PASSWORD=666 python -m vad2mqtt
```

## Key files

| File | Role |
|------|------|
| `vad2mqtt/__main__.py` | CLI entry point |
| `vad2mqtt/audio.py` | sounddevice InputStream + VAD callback loop |
| `vad2mqtt/vad_engine.py` | OPM VAD plugin wrapper (any plugin) |
| `vad2mqtt/mqtt_client.py` | MQTT pub + HA discovery payloads |
| `vad2mqtt/config.py` | All env-var config |
| `docs/homeassistant.md` | HA integration docs + Area Occupancy Detection |

## Architecture notes

- Uses `ovos-plugin-manager` (`OVOSVADFactory`) to load any VAD plugin.
- Extracts raw probability from the ONNX model via `engine.vad(frame)`.
- `InputStream` callback (not `RawInputStream`) — numpy arrays.
- Noise level throttled by interval + delta.
- MQTT retry with exponential backoff (5 attempts).
